# Modules Manager 2.2.3-ru.1

Первый стабильный релиз русифицированного форка.

## Что изменилось

- Русифицированы основные экраны, навигация, настройки, фильтры, карточки модулей, сведения о релизах и диагностика.
- Русский язык включается автоматически при русском языке Android; для остальных языков сохраняется английский интерфейс.
- Переведены сообщения об установке, обновлениях, ошибках репозиториев и фоновых загрузках.
- Восстановлено оригинальное название приложения — Modules Manager.
- Сохранены исходный application ID, namespace и Xposed/LSPosed metadata.
- Добавлены CI-проверки и сборка подписанного release APK через GitHub Actions.

## Совместимость и переход

- Android 8.1 (API 26) и новее.
- Package: `io.github.rushiranpise.modulesmanager`.
- Подпись форка отличается от официальной подписи оригинального приложения.
- Preview APK из GitHub Actions подписан временным debug-ключом; для перехода на стабильную release-сборку может потребоваться переустановка. Сначала сохраните данные приложения.
- Все следующие релизы должны подписываться тем же постоянным ключом форка.
