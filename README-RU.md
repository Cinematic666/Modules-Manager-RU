# Modules Manager

Русифицированный форк Android-приложения Modules Manager для поиска, установки и обновления модулей Xposed/LSPosed.

## Релиз

- Название приложения: **Modules Manager** — оригинальное название сохранено.
- Версия форка: `2.2.3-ru.1` (versionCode `14`).
- Application ID: `io.github.rushiranpise.modulesmanager` — сохранён.
- Минимальная версия Android: 8.1 (API 26).
- Русский интерфейс включается автоматически при русском языке системы; на остальных языках используется английский интерфейс.
- Английские технические термины, названия проектов и идентификаторы пакетов сохраняются там, где перевод ухудшил бы точность.

## Сборка и проверки

Требуются JDK 21 и Android SDK 37.

```bash
./gradlew :app:testDebugUnitTest
./gradlew :app:assembleDebug
./gradlew :app:assembleRelease
```

GitHub Actions проверяет unit-тесты и собирает debug APK для каждого изменения в `dev` и `main`. Публикация подписанного release APK выполняется по тегу вида `v2.2.3-ru.1`.

## Подпись APK и обновления

Release APK подписывается отдельным ключом этого форка. Ключ подписи необходимо сохранить в нескольких безопасных резервных копиях: потеря ключа не позволит выпускать обновления, устанавливаемые поверх уже опубликованной версии.

Для автоматической сборки релизов в GitHub Repository Secrets должны быть добавлены:

- `ANDROID_KEYSTORE_BASE64` — содержимое JKS-файла в Base64.
- `ANDROID_KEYSTORE_PASSWORD` — пароль хранилища.
- `ANDROID_KEY_ALIAS` — alias ключа.
- `ANDROID_KEY_PASSWORD` — пароль ключа.

Сборка из предыдущего debug-preview подписана временным debug-ключом GitHub Actions. Она не может быть обновлена release APK с постоянным ключом. Перед переходом с preview потребуется сохранить данные приложения и переустановить его. Последующие релизы с тем же release-ключом будут устанавливаться поверх предыдущих версий.

Подпись форка отличается от подписи оригинального приложения. Поэтому форк не может обновлять официальный APK поверх него без удаления оригинала.
