# Modules Manager RU

Русифицированная версия Modules Manager — приложения для поиска, установки и обновления модулей Xposed/LSPosed.

## Состояние проекта

- Основа: upstream Modules Manager 2.2.3.
- Оригинальный репозиторий и его ветка `main` не изменяются.
- Разработка русификации ведётся в ветке `dev`.
- Стабильные изменения будут переноситься в `main` после проверки.
- Английский интерфейс сохраняется; русский интерфейс включается автоматически при русском языке системы.

## Сборка

Требуются JDK 21 и Android SDK 37.

```bash
./gradlew :app:testDebugUnitTest
./gradlew :app:assembleDebug
```

После каждого push в `main` или `dev` GitHub Actions запускает модульные тесты и сборку debug APK. APK доступен в артефактах успешного запуска Actions.

## Подпись и установка

Сборки этого форка подписываются не оригинальным ключом разработчика. Поэтому они не могут обновлять официальное приложение поверх установленной версии. Для перехода на форк может потребоваться удалить оригинальную версию. Перед удалением сохраните важные данные приложения.
